## How to use this file

- One row per **source video** in the top table — add a new row the moment
  a new YouTube link is shared, even before any reels exist yet.
- One sub-table per source video for its individual reels, named
  `## <slug> — reel detail`.
- Keep `Status` short and current: e.g. "Built — not yet uploaded",
  "Uploaded, public", "Needs rebuild — <reason>".
